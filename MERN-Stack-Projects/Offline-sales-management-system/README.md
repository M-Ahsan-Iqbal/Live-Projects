# Offline sales management system

A full-stack MERN application built for field sales agents to manage store visits, track SKUs, monitor competitor products, complete surveys, and generate reports.

## 🚀 Live Demo
[Live Demo](https://offlinesales-ksa.air.global/)

## 📌 Features

### 👨‍💼 Agent Management
- Secure Login / Authentication
- Profile Management
- Role-based Access

### 🏪 Store Visit Management
- Schedule Daily / Weekly Visits
- Check-in / Check-out at Stores
- Route Overview Dashboard
- Visit Status Tracking (Pending, In Progress, Completed)

### 📦 SKU Management
- Check Available Company SKUs
- Record Out-of-Stock Products
- Add Product Visibility Details

### 🏷️ Competitor Analysis
- Add Competitor SKUs
- Compare Competitor Presence
- Competitor Product Tracking

### 📝 Survey Module
- Fill Store Surveys
- Collect Feedback
- Custom Survey Questions

### 📊 Reports & Analytics
- Daily Visit Reports
- Agent Performance Reports
- SKU Reports
- Survey Reports
- Dashboard Statistics

### 📍 Dashboard
- Today's Summary
- Completed Visits
- Pending Visits
- In Progress Visits
- Route Overview
